# AI Learning Assistant

An AI-powered learning assistant built with Python and Ollama.

## Features

- Learn any topic with AI-generated courses
- Step-by-step lessons
- Progress tracking
- Automatic save/load
- Local LLM (Qwen3 via Ollama)
- Terminal interface

## Tech Stack

- Python
- Ollama
- Qwen3:8B
- JSON
- Git

## How to Run

```bash
pip install ollama
ollama pull qwen3:8b
python main.py
